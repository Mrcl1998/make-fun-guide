You don't need to be an expert coder. Many participants use an AI agent to build their entry — the agent writes the code, tests it, and prepares the submission. Your job: bring the idea, steer the agent, and submit before the deadline.

1. Pick a bounty and read its rules page all the way through — every bounty has its own rules and judging criteria.
